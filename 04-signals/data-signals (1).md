## Leading indicators

- **Get Started Import Feature Usage %:** Import is the first step of activation and the point where day-1 drop-off happens, so a user who never imports can never reach the North Star.
- **Financial Modeling Feature Usage %:** It is the last step before the North Star, so a guided path that lifts it should lift the North Star in the same weeks.

_____

## Lagging indicators

- **Trial-to-Paid Conversion Rate:** It has hit a ceiling that ad spend cannot break, so a rise proves that better activation, not more traffic, drove growth.
